# Как открыть almaz-surgut.ru без VPN: перенос на российский хостинг

Сайт сейчас обслуживается GitHub Pages. Этот документ для владельца «Студии заточки Алмаз», Сургут.

## 1. Сначала подготовьте хостинг

Домен у Спринтхост, но покупка домена **не означает**, что у него есть действующий тариф хостинга.
Убедитесь в панели Спринтхост, что доступен хостинг с размещением статического сайта.
Создайте сайт `almaz-surgut.ru` в разделе «Сайты» → «Добавить сайт».

## 2. Перенесите файлы

- На GitHub откройте `https://github.com/sokratyspex-dot/almaz-surgut` → **Code** → **Download ZIP**.
- Распакуйте ZIP. Загрузите **содержимое** папки репозитория, а не саму папку, через файловый менеджер или FTP в `domains/almaz-surgut.ru/public_html/`.
- В корне папки должен лежать файл `index.html`. Вместе с ним нужны `robots.txt`, `sitemap.xml`, `analytics.js`, `site-config.js`, четыре страницы услуг, логотип и все остальные файлы сайта.
- Файл `CNAME` нужен GitHub Pages; на Спринтхост его можно не загружать.
- Проверьте технический домен хостинга (если доступен), прежде чем менять DNS. Сохраните рабочую копию GitHub.

## 3. Переключите домен только после успешной проверки хостинга

В панели управления DNS доменом `almaz-surgut.ru`:
- Замените существующие A-записи `@`, ведущие на GitHub Pages (`185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`), на **реальный IPv4 созданного сайта**, который показывает Спринтхост. Не придумывайте IP.
- Если есть старые AAAA-записи GitHub Pages, удалите их либо замените на IPv6 Спринтхост, если провайдер его предоставил.
- Настройте `www` как дополнительное имя сайта с перенаправлением на `https://almaz-surgut.ru/`.
- Не удаляйте почтовые MX, SPF, DKIM и прочие TXT-записи.
- Подключите SSL-сертификат для домена, проверьте HTTPS и перенаправление с HTTP.
- **Не меняйте DNS до загрузки и проверки файлов**, иначе сайт может временно пропасть.

## 4. Индексация

- Откройте `https://almaz-surgut.ru/robots.txt` и `https://almaz-surgut.ru/sitemap.xml` после переноса. Оба должны возвращать HTTP 200.
- В Яндекс.Вебмастере подтвердите сайт и добавьте `https://almaz-surgut.ru/sitemap.xml`. Отправьте главную страницу на переобход.
- В Google Search Console добавьте этот же sitemap и запросите индексирование главной.
- Убедитесь в доступности сайта **без VPN** на телефоне в Сургуте через мобильную сеть и домашний интернет.

## Важное

После переноса изменения в GitHub не появятся на Спринтхост автоматически: нужно повторно переносить изменённые файлы или позже настроить автоматическое развёртывание.
