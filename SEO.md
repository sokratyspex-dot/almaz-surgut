# SEO и посещаемость

Основной адрес: https://almaz-surgut.ru/

В index.html настроены title, description, canonical, Open Graph, favicon,
заголовок о заточке в Сургуте и JSON-LD с услугами и ценами.
robots.txt разрешает обход; sitemap.xml содержит основной URL без якорей.

## Запуск Яндекс.Метрики

Создать счётчик для https://almaz-surgut.ru/ в https://metrika.yandex.ru/add
или использовать существующий. В site-config.js заменить metricaId: 0
на номер своего счётчика. Пока номер равен 0, счётчик не загружается,
посещения и цели не собираются. Не использовать чужой номер.

Создать цели типа «JavaScript-событие» с идентификаторами:

| Идентификатор | Действие |
| --- | --- |
| click_phone | Нажатие на телефон |
| click_telegram | Открытие Telegram по ссылке |
| click_max | Открытие MAX по ссылке |
| click_whatsapp | Открытие WhatsApp по ссылке |
| open_request | Переход к форме |
| request_telegram | Открытие Telegram из формы |
| request_max | Открытие MAX из формы |
| request_whatsapp | Открытие WhatsApp из формы |
| select_category | Выбор категории инструмента |

Открытие мессенджера не подтверждает отправку сообщения или оплату.
В аналитику не передаются имя, комментарий и текст заявки.
Вебвизор и карта кликов выключены.
После включения проверить init и цели с ?_ym_debug=2 и в отчётах Метрики.

## Индексация

В Яндекс.Вебмастере и Google Search Console добавить основной адрес,
подтвердить владение предоставленным сервисом токеном и отправить
https://almaz-surgut.ru/sitemap.xml. Токены подтверждения здесь не выдуманы.
Для локального поиска дополнить карточку бизнеса точным адресом,
часами работы и ссылкой на сайт, когда мастер подтвердит эти данные.
Настройки SEO не гарантируют индексацию или позицию в поиске.
